# Cassowary-Storage
### IMPORTANT 
**icon.png and the icon generally All Rights Reserved** <br>
Cassowary Storage is a lightweight, Python-based WebDAV client for Linux featuring a native GNOME libadwaita interface. You can configure automated backups and sync files across multiple WebDAV Servers.

## How to install
**Newest Release** [https://github.com/mydigital24/Cassowary-Storage/releases/tag/Release](https://github.com/mydigital24/Cassowary-Storage/releases#release-release)
### Use the Python file
Download the Python file.
#### Dependencies
- Python 3 (python3)
- PyGObject 
- GTK 4
- libadwaita
  
**Installation:** <br>
Fedora:<br> ``` sudo dnf install python3-gobject gtk4 libadwaita ``` <br>
Ubuntu / Debian: <br> ``` sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-4.0 gir1.2-adw-1 ```
### Use Flatpack
Download the file **cassowary.flatpack**. Then open it and install with Software like Gnome Software or Bazaar.
