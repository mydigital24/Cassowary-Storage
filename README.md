# Cassowary-Storage
### IMPORTANT 
**icon.png and the icon generally All Rights Reserved** <br>
Cassowary Storage ist ein schlanker WebDAV-Client für Linux basierend auf Python.

## How to install
**Newest Release** https://github.com/mydigital24/Cassowary-Storage/releases/tag/Release
### Use the Python file
Download the Python file.
#### Dependencies
- Python 3 (python3)
- PyGObject 
- GTK 4
- libadwaita
<br>
**Installation:**
Fedora: sudo dnf install python3-gobject gtk4 libadwaita
Ubuntu / Debian: sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-4.0 gir1.2-adw-1
### Use Flatpack
Download the file **cassowary.flatpack**. Then open it and install with Software like Gnome Software or Bazaar.
